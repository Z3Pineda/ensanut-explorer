## Data changes

- **Lactancia 2021–2023:** `meta.json`, `summary.json`, and downloadable `data.csv` now use short names (`amamantar`, etc.) with `source_column` traceability
- **All modules:** `data.csv` in `docs/data/` is written from the processed dataframe (not a raw copy of `ZENODO/`), keeping columns aligned with `meta.json`

Aggregates outside lactancia 2021–2023 are unchanged except where `data.csv` column alignment fixes integrity checks (no statistical recomputation).

## Remaining limitations

- Actividad física: different variable schemas in 2018 vs 2022–2023
- Lactancia 2018: ~65 variables not present in 2021–2023 waves
- Lactancia 2021–2023: `no_trabajar` and some `ayer_*` items not in 2018
- `EDAD_MADRE` only in 2018
- Alimentos: generated `description.json` where INSP JSON is unavailable
